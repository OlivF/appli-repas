# Étape 3 bis : dans le frigo : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un frigo par foyer (restes libres, articles réservés au menu d'une semaine, dates limites), déduit de la liste de courses sans double comptage et soldé en fin de semaine.

**Architecture:** calcul pur dans `lib/fridge.ts` et `lib/shopping.ts` (stock libre, signature, bilan, besoin exact), testé avec Vitest. Postgres garde les invariants (foyer recopié, unité d'achat, RLS) et applique les écritures groupées en une transaction (`sync_shopping_list`, `apply_fridge_settlement`). Les écrans lisent par `lib/fridge-data.ts` / `lib/shopping-data.ts` et écrivent par Server Actions, en optimiste.

**Tech Stack:** Next.js 16 (App Router, Cache Components), Supabase (Postgres 17, RLS, pgTAP), Tailwind, shadcn/ui (+ `sonner`), framer-motion, lucide-react, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-19-frigo-design.md`

## Global Constraints

- Branche `frigo` depuis `main` (dc42abe). Migration `0011_fridge.sql`. Types : `supabase gen types typescript --local --schema public > lib/supabase/database.types.ts`.
- Arrêt pour validation après A (Tasks 1-3) et après B (Tasks 4-6). PR vers `main` à la fin de C.
- Quantités dans l'unité d'achat (`g`, `ml`, `piece`) ; reste de plat : parts, `unit` null. Quantité inconnue = null, jamais déduite.
- `SOON_DAYS = 2` ; reliquat supprimé : < 10 g, < 10 ml, < 0,5 pièce.
- Dates : `todayInParis()` et `addDays()` de `lib/week.ts` (AAAA-MM-JJ, UTC).
- Textes au tutoiement, exacts : « Frigo », « Ajouter au frigo », « À finir vite », « Restes », « Pour le menu de la semaine », « Fini », « Annuler », « Ranger », « C'est un reste », « Rien au frigo pour l'instant », « Après le drive, range tes courses ici : l'appli s'en servira pour ta prochaine liste. », « Aujourd'hui », « Demain », « Dans 3 jours », « Dans 1 semaine », « Choisir… », « Pas de date », « Le menu a changé », « Le frigo a changé », « Mettre à jour la liste », « + 200 g au frigo », « Tu en as peut-être au frigo », « Au frigo : 200 g, jusqu'au mar. 24 », « Courses faites ? Range-les au frigo », « Plus tard », « Non merci », « Ranger au frigo », « Ranger N articles », « Pas cuisiné », « Il en reste », « Rangé au frigo », « À finir : … ».
- Cibles tactiles ≥ 48 px ; composants existants ou variantes montrées sur `/design`, aucun style ad hoc.
- Formulaire pré-rempli → `key` dérivée de la donnée enregistrée ; e2e en `getByRole`, `test` importé de `./fixtures`.

## Review Focus
