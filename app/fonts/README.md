# Polices embarquées

`fraunces-600-soft.ttf` : Fraunces, instance statique graisse 600, SOFT 100, opsz 72, téléchargée
depuis Google Fonts. Elle sert à générer l'image de partage (`app/opengraph-image.tsx`), qui ne peut
pas utiliser `next/font`. Les pages, elles, chargent Fraunces avec `next/font/google`.
